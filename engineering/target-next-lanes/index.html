    A10 follow-up: interrupt-chained transmit completion — 2026-10-15

    IMPLEMENTED candidate — Codex, branch lane/a10-uarte-completion-irq-20261015. The first source-built stack guest and deterministic release remain passing bounded evidence. Lite PR988's actual compiled MakeCode CLI guest nevertheless failed both complete-line checks: serial begins hl bw rather than hello bw. Preserve that failure; consumer integration remains held.

    Review found that UARTE completion unconditionally raises TXSTOPPED alongside ENDTX, whereas the nRF52833 specification associates TXSTOPPED with STOPTX. An interrupt handler that starts its next byte on ENDTX can then process the spurious stop event and clear the new transfer's busy state. Correct this event separation in crates/core/src/peripherals/nrf52/uarte.rs, retain STARTTX buffer capture and framed completion, and add nonvacuous interrupt-chain controls. Extend the original assembly guest and native guest test to cover that sequence at exact and recommended intervals.
