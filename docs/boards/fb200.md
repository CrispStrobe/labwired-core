# FLAMMA FB200 bass pedal (NXP i.MX RT1052)

A Cortex-M7 (FPv5-D16) bass multi-effects pedal. The SoC close-up photos read
MIMXRT1052 DVL6B. Hardware reference: the open
[fb200-tools](https://github.com/w1ne/fb200-tools) project
(`docs/HARDWARE.md`, `docs/AUDIO_PATH.md`, `docs/UI_AND_STORAGE.md`).

## Status at a glance

|---------------|-------------------------------------------------------------------------|
| Chip yaml     | [`configs/chips/mimxrt1052.yaml`](../../configs/chips/mimxrt1052.yaml)   |

| Tier          | **smoke-manual**: boots firmware and prints, **no silicon diff**        |

## What is proven

- The open smoke firmware boots from FlexSPI XIP at `0x60010000`, un-gates
  CCM CCGR3, prints `RT1052 SMOKE OK` on LPUART5 and toggles GPIO4_IO00.
- `mimxrt1052_fb200_stock_boot` boots the unmodified vendor V1.0.1 `.mr`
  image through its own loader to USB enumeration (`34DB:800F`): clocks,
  FlexSPI NOR, factory reset on blank flash, LPI2C1, FlexIO2 WS2812 frame,
  14-segment GPIO multiplex, Bluetooth AT sequence on LPUART5. The vendor image
  is not redistributable, so this test runs only when
  `LABWIRED_FB200_STOCK_MR` points at it; in CI it does not run.

## What is not proven

No silicon diff and no executing-fidelity differential. Board parts are not
modelled yet: the NAU88L21 codec (LPI2C1 `0x54` NACKs), the 74HC4051 knob
muxes, the 14-segment display part, the footswitches and the Bluetooth module.

## How to run

```bash
labwired test --script examples/fb200/io-smoke.yaml
```
